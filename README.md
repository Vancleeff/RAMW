RAMW
======

RAMW is a special build of [Open Morrowind](https://gitlab.com/OpenMW/openmw/) focus on achievement integration for retroachievements.com

It is currently in alpha test with the community.

No guarentee that the final build will be approved by both team.

Alpha test is private for now, you can contact me on discord (vancleeff) if you want to join the testers.
