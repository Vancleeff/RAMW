RAMW
======

RAMW is a special build of [Open Morrowind](https://gitlab.com/OpenMW/openmw/) focused on achievement integration for retroachievements.com

It's currently in alpha test with the community.

No guarentee that the final build will be approved by both teams.

Alpha test is private for now, you can contact me on discord (vancleeff) if you want to join the testers.
